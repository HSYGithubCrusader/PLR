# Daily Operating Rule

Use this at the start of every project session.

## 1. Read
- `CURRENT_STATE.md`
- `NEXT_TASK.md`

## 2. Ask
What single action today most increases the probability of a paying client?

## 3. Timebox
On a normal workday:

```text
10 min  orient / update state
90 min  highest-value work
20 min  test/log/update docs
```

After Day 7, the 90-minute block defaults to sales/prospecting, not coding.

On a full day off:

```text
Block 1  high-focus build or prospect research
Block 2  test / review
Block 3  outreach / demos
Block 4  follow-up / documentation
```

## 4. End Every Session
Update:

- `CURRENT_STATE.md`
- `NEXT_TASK.md`
- prospect tracker if sales activity occurred
- `DECISIONS.md` if a significant choice was made

## 5. Do Not Start a Side Quest
Any new idea goes into `docs/BACKLOG.md` and is not implemented unless it passes the scope gate.
